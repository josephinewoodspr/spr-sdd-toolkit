# Spec Roadmap

**This file answers "what's next?"** It's the backlog of planned specs, in order, derived from {requirement docs / backlog}. When `/new-spec` creates a spec folder, that row gets its number and moves to Numbered. From then on, the status column follows the spec's own frontmatter. Numbers are assigned **only when the folder is created**, so planned rows have no number yet.

Status of every spec:

```bash
grep -H "^status:" specs/*/spec.md
```
